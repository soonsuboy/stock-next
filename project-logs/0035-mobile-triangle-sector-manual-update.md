# 0035 모바일 삼각형 확대와 섹터 수동 변경

## 요청
- 분석 화면의 삼각형 다이어그램이 PC에서는 보기 좋지만 스마트폰 세로 화면에서는 작게 보이므로 약 1.7배 크게 보이게 개선.
- 관심종목에서 `미분류` 섹터를 사용자가 직접 선택할 수 있게 하고, 이미 분류된 섹터도 사용자가 잘못됐다고 판단하면 다시 선택해 저장할 수 있게 개선.
- 작업 후 로그 작성, 커밋, GitHub 푸시까지 자동 진행.

## 판단
- 삼각형 SVG는 PC 폭에서는 충분하지만 모바일에서는 카드 폭에 맞춰 축소되고 있었다.
- 모바일 세로 화면에서 1.7배 확대하면 화면 폭을 넘기 때문에, 다이어그램 영역만 가로 스크롤 가능하게 두는 방식이 가장 안정적이다.
- 섹터 수동 변경은 사용자별 관심종목 ID로 권한을 확인한 뒤 `companies.gics_sector`를 업데이트하도록 구현했다. 동일 기업의 섹터는 회사 마스터 기준으로 공유되는 값이므로, 수동 변경 출처를 `sector_source = user_manual`로 남긴다.

## 구현
- `app/analysis/page.tsx`
  - 삼각형 SVG를 `overflow-x-auto` 래퍼로 감쌌다.
  - 모바일 기본 폭은 `w-[170%]`, `sm` 이상에서는 기존처럼 `w-full`로 동작하게 했다.
- `app/watchlist/page.tsx`
  - 관심종목 카드의 섹터 표시를 선택 가능한 `select` UI로 변경했다.
  - GICS 11대 섹터 목록을 옵션으로 제공했다.
  - 저장 중 상태와 `수동` 배지를 추가했다.
  - 저장 성공/실패 메시지를 기존 배치 메시지 영역에 표시하게 했다.
- `app/api/watchlist/[id]/route.ts`
  - `PATCH` 메서드를 추가했다.
  - 로그인 사용자 소유의 관심종목인지 확인한 뒤 선택된 섹터를 저장한다.
  - 허용되지 않은 섹터 값은 400으로 차단한다.

## 다음 에이전트 인수인계
- 섹터 수동 변경은 회사 마스터 값을 직접 바꾸므로, 같은 기업을 보는 다른 사용자도 변경된 섹터를 보게 된다.
- 사용자별 개인 섹터 오버라이드가 필요해지면 `user_company_sector_overrides` 같은 별도 테이블로 분리하면 된다.
- 모바일 삼각형은 가로 스크롤 방식이다. 화면 안에 반드시 전부 맞춰야 한다는 요구가 생기면 SVG 내부 글자와 박스 크기를 별도 모바일 viewBox로 재배치하는 방식이 더 적합하다.
