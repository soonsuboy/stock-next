# 0042 - 종목검색 집계 기업 그리드와 페이징

## 요청
- 종목검색의 집계 기업 카드 목록을 엑셀 같은 그리드 형식으로 바꾼다.
- 그리드 상단에 한국/미국 주식 탭을 둔다.
- 30개씩 표시하고 하단 페이지 번호로 다음 데이터를 볼 수 있게 한다.
- 그리드 맨 왼쪽 체크박스로 여러 종목을 선택하고, 선택 종목을 관심종목에 추가할 수 있게 한다.
- 그리드 컬럼은 기업명, 섹터, 시가총액, ROE, PBR, PER, 가격, 전일가격, 등락률을 표시한다.

## 계획
1. `/api/search/ranked`에 `country`, `page`, `limit` 파라미터와 전체 건수/전체 페이지 응답을 추가한다.
2. API 조회 결과에 `companies.gics_sector`를 포함한다.
3. 검색 화면의 집계 기업 영역을 카드형에서 테이블 그리드로 전환한다.
4. 한국/미국 탭, 30개 페이징, 페이지 번호를 추가한다.
5. 체크박스 선택 상태와 선택 종목 일괄 관심종목 추가 동작을 구현한다.

## 구현 내용
- `/api/search/ranked`
  - `country=KR|US` 기준으로 한 시장만 조회하도록 변경했다.
  - `page`, `limit` 기반 `LIMIT/OFFSET` 페이징을 추가했다.
  - 같은 조건의 `COUNT(*)`를 함께 조회해 `total`, `totalPages`를 반환한다.
  - `gics_sector`를 반환하고, 섹터 컬럼이 없는 기존 DB에도 안전하도록 `ensureCompanySectorColumns()`를 호출한다.
- `app/search/page.tsx`
  - 집계 기업 표시를 카드 2열에서 테이블 그리드로 변경했다.
  - 한국/미국 탭으로 시장을 전환한다.
  - 페이지당 30개, 하단 페이지 번호/이전/다음 버튼을 추가했다.
  - 체크박스 전체 선택/개별 선택을 지원한다.
  - 선택 종목을 일괄 관심종목에 추가하는 버튼을 추가했다.
  - 컬럼: 기업명, 섹터, 시가총액, ROE, PBR, PER, 가격, 전일가격, 등락률.

## 다음 에이전트 인수인계
- 현재 그리드는 선택한 종목을 순차적으로 `/api/watchlist`에 POST한다.
- 페이지를 이동해도 선택 상태는 유지되므로, 여러 페이지에서 선택한 뒤 한 번에 관심종목에 추가할 수 있다.
- 이미 추가된 종목은 체크박스가 비활성화되고 이름 아래에 `추가됨`이 표시된다.
